# 🔥 FireAI — сайт

Лендинг проекта **[FireAI](https://github.com/m3ufree/FireAI)** — очень умного ИИ, который делает 3D-игры, пишет песни и знает все языки программирования. Со своим OpenAI-совместимым API.

**Сайт:** https://m3ufree.github.io/FireAI-Site/

Дизайн — в стиле max.ru: светлая тема, анимированное градиентное пятно в шапке, сине-фиолетовая палитра.

## Размещение
Статический сайт, автоматически публикуется через GitHub Pages из ветки `main`.
